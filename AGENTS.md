# Project: Nestjs/websockets

A prototype and idea project for live time game sessions and leaderboard

## Stack

- NestJS, TypeScript, PostgreSQL, Drizzle ORM

## Commands

- Run dev: `npm run start:dev`
- build: `npm run build`
- Lint: `npm run lint`

## Rules

- Follow the existing folder structure (one folder per module).
- Don't add new libraries without asking.
- Write tests for new services.
- Keep changes small; don't refactor unrelated code.

## Skills

- For creating a new module, use the `module` skill.
