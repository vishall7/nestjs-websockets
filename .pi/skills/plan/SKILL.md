# Plan Skill

Create a concise plan before implementation.

1. Clarify the goal and expected behavior.
2. Inspect relevant files, architecture, and project instructions.
3. Identify affected modules, interfaces, data changes, and dependencies.
4. List the implementation steps in execution order.
5. Define tests and verification commands.
6. Note assumptions, risks, and open questions.

Keep the plan specific to the repository, avoid unnecessary refactoring, and do not edit files unless explicitly asked.
