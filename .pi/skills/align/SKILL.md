# Align

Interview the user until no open questions remain. Do not write code or files.

1. If a codebase exists, inspect it first. Never ask what the code can answer.
2. Ask ONE question at a time, with your recommended answer.
3. Cover what's relevant: goal, users, behavior, edge cases, constraints, scope, out-of-scope, success criteria.
4. Challenge vague or conflicting answers.
5. Use the project's own terminology.
6. When nothing is open, summarize the agreement in max 8 lines and ask: "Aligned?"
7. If not aligned, keep asking.
